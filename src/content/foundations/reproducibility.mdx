## Минимальный manifest
Чтобы повторить расчёт, сохраните вход, параметры, версию алгоритма и ожидаемый результат. Для случайного метода добавьте seed и бюджет; для детерминированного выравнивания seed не нужен.

Эксперимент Needleman–Wunsch выполняется локально в браузере. Кнопка экспорта создаёт JSON с исходными строками, системой оценок, матрицей и найденными ответами. Никакой сервер не получает введённые последовательности.

## Расчёт и просмотр
B — новое вычисление в браузере. P — воспроизводимое происхождение заранее рассчитанного набора. R — просмотр сохранённой trace; изменение камеры не пересчитывает исходный анализ. S — отдельный вычислительный сервис, которого в этой версии нет.

Файл предрасчёта сопровождают версия producer, команда воспроизведения, параметры и контрольная сумма. Для тяжёлых задач автор публикует только подготовленные данные; исходные чувствительные данные не добавляют в учебный репозиторий.

## Проверка результата
Сначала сравните независимый маленький эталон, затем свойства функции и связь визуального состояния с числами. Успешная сборка сайта проверяет инфраструктуру; численные контроли проверяют алгоритм. Ни то ни другое не доказывает биологический вывод.
