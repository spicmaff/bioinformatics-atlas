# Биоинформатика: методы и алгоритмы

Русскоязычный статический интерактивный атлас. **Готова одна глава M01: глобальное выравнивание Needleman–Wunsch.** Программа содержит 35 модулей (17 ядра, 13 углублений, 5 смежных), 4 кандидата и все 43 исторических ID. Первый выпуск M13, M01, M06, M19, M20, M17 остаётся планом расширения; наличие модуля в программе не означает готовность его текста.

## Запуск

Нужен Node.js **24.22.1** (ветка 24 LTS; `.nvmrc`, `.node-version`, `engines`); npm 11.9.0. Все прямые зависимости закреплены точными версиями, транзитивные — `package-lock.json`.

```sh
nvm use
npm ci
npm run dev
```

Откройте адрес из терминала с префиксом `/bioinformatics-atlas/`. Для просмотра черновиков:

```sh
npm run dev:drafts
```

Эта команда предназначена для POSIX shell (Linux/macOS, WSL). В PowerShell: `$env:INCLUDE_DRAFTS='1'; npm run dev`. Не публикуйте такой просмотр: черновики локальные. Production build с `INCLUDE_DRAFTS=1` намеренно запрещён.

## Проверки и сборка

```sh
npm run check
npm run preview
```

`check` проверяет схему контента, ID и зависимости, типы Astro/React/TypeScript, независимые эталоны алгоритма, production build, внутренние URL/якоря/ресурсы, отсутствие черновых страниц, наличие Pagefind и sitemap. Проверка ссылок требует уже собранного `dist/`.

Раздельные команды: `check:content`, `check:types`, `test`, `build`, `check:links`. Установка в CI — только `npm ci`. Сборка статическая, backend и секреты для учебных вычислений не нужны.

## Добавить следующую главу

```sh
npm run new:chapter -- --module M01 --slug smith-waterman --title "Локальное выравнивание Smith–Waterman"
npm run dev:drafts
```

Команда создаст `src/content/chapters/m01/smith-waterman.mdx` с новым стабильным ID и `status: draft`. Заполните MDX и frontmatter, источники и контроли; если нужен новый алгоритм — разработайте его отдельно. После содержательной и численной проверки смените статус на `published`, выполните `npm run check` и отправьте изменения через pull request в `main`. Каталог модуля, ссылки и навигация обновятся из метаданных. Подробные примеры — [руководство автора](docs/AUTHORING.md).

## Навигация и оформление

Главная — атмосферный вход. Каталог `/catalog/` — анимированный выбор модулей по восьми направлениям. Страница модуля ведёт к темам, страница темы — к упорядоченным алгоритмам. У M01 реализована тема «От префикса к матрице» с доступной главой Needleman–Wunsch; продолжения явно отмечены как готовящиеся.

Темы хранятся в `topics` метаданных модуля; глава ссылается на тему полем `topic`. URL существующих глав сохранены. Уточнённая визуальная спецификация — [docs/DESIGN.md](docs/DESIGN.md).

## Структура

- `src/content/modules/`: единственный источник метаданных 35 модулей и редакторского текста.
- `src/content/chapters/`: самостоятельные MDX-главы; несколько глав могут принадлежать одному модулю.
- `src/content/foundations/`, `src/content/theory/`: общие опоры и теория в одном экземпляре.
- `src/content/docs/index.mdx`: главная Starlight; каталог и служебные страницы — `src/pages/`.
- `src/data/`: восемь веток, библиография, маршруты чтения, восемь исторических решений.
- `src/lib/schema.ts`: проверяемый контракт данных; `content.ts`: чтение, разрешение ID и URL.
- `src/algorithms/`: чистые вычисления; `src/components/experiments/`: представление и управление.
- `src/experiments/registry.ts`: разрешённые механизмы, версии и режимы.
- `public/examples/v1/`: версионированные данные и manifest предрасчёта; producer в `scripts/precompute/`.
- `templates/`: исходники для авторских команд.
- `docs/06_site_plan_v2.md`: неизменённый предоставленный источник программы и визуальной спецификации.

## Публикация

Репозиторий: `https://github.com/spicmaff/bioinformatics-atlas`.
Целевой адрес Pages: `https://spicmaff.github.io/bioinformatics-atlas/`.

В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Это единственная настройка Pages, если ещё не выполнена. Workflow **Checks** выполняется для PR и `main`; отдельный **Publish GitHub Pages** запускается только после успешной проверки `main` и публикует артефакт именно этого запуска. Непроверенный PR не получает права Pages. Секреты PAT не нужны: используются минимальные права встроенного GITHUB_TOKEN и OIDC. Основная ветка — `main`.

`astro.config.ts` задаёт `site`, `base` и trailing slash. `withBase()` добавляет префикс страницам и локальным данным; шрифты и KaTeX включены в сборку. При изменении владельца/имени репозитория обновите site/base и ссылки проекта, затем выполните проверку URL; custom domain сейчас не используется.

## Реализовано и запланировано

Работают: главная, каталог с фильтрами, программа восьми веток, два маршрута, M01 с перечнем глав, законченная глава NW, четыре опоры, общая теория ДП, словарь и источники. Интерфейс включает локальные кириллические IBM Plex, KaTeX HTML+MathML, Pagefind, видимый фокус, клавиатурную матрицу и reduced motion.

Планируются: остальные главы M01 и остальных модулей, аффинные/локальные/fitting/overlap выравнивания, остальные экспериментальные механизмы и реальные omics-workflow. Генератор предрасчёта показывает формат подключения данных; тяжёлый анализ и внешние сервисы не реализованы.

Научная программа не меняется автоматически: K04 — core; K02→M08, K05→M28, K07→M26, K08→F-BIO и кейсы. Следующие свободные ID на исходной программе — M36/K09. Кандидаты не создают пустых уроков.
