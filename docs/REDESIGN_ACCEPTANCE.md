# Проверка новой оболочки — 27 октября 2026

## Реализовано

- Короткая главная со сценой кабинета и входом в учебник; прежние матрица, сводка и длинные вводные разделы с неё убраны.
- Выбор восьми направлений и переключение 35 модулей без перезагрузки страницы. Поиск по названию, вопросу, методу и историческим ID; выбранный модуль сохраняется в URL.
- Явный путь модуль → тема → упорядоченные алгоритмы. У M01 доступны тема «От префикса к матрице» и глава Needleman–Wunsch. Планируемые темы и алгоритмы подписаны; пустых учебных страниц нет.
- Темы — в метаданных модуля, принадлежность главы — в поле topic. Сохранены адреса существующих глав, 43 исторических ID и редакторские роли 17/13/5.
- Тёмная оболочка, кириллическая книжная типографика, пиксельные акценты, управляемое декоративное движение. Новые главы наследуют оформление.

## Фактически проверено

- npm ci и npm run check: схема и зависимости, типы, численные тесты, production build, 524 внутренних ссылки/ресурса/якоря. Сборка даёт 17 HTML-страниц, Pagefind и sitemap. Проверка типов: 0 ошибок, предупреждений и подсказок.
- В браузере перечислены модули всех восьми направлений: 35 уникальных ID. Проверены клавиатурные стрелки между вкладками, поиск K02 → M08, пустая выдача и сброс.
- Переключатель движения устанавливает reduced и действительно убирает CSS animation. Системный prefers-reduced-motion также поддержан.
- Пройден весь путь с главной до темы и алгоритма. На широком экране осмотрены главная, навигатор, модуль, тема, глава и поиск.
- На viewport 320 px осмотрены главная, каталог, модуль, тема и глава. Глобальной горизонтальной прокрутки после загрузки нет. Длинная матрица прокручивается внутри своей панели: 24×24 буквы, score 48, 1337 px содержимого при 239 px панели.
- В браузере: ACG/ACG → 6; пустая/AC → −4; A/AA → 0 и два оптимума. Сохраняются пошаговое заполнение, traceback, предупреждение о старом расчёте и отказ для N. Все 225 независимых численных сравнений также проходят.
- В главе — 13 MathML-элементов. Поиск находит Needleman–Wunsch; поле ввода, кнопка очистки и ширина диалога проверены после исправления наложения стилей. Кнопка очистки — 44 px, горизонтального переполнения диалога нет.
- Штатная команда создала временную главу с topic: M01-T01; production исключил её HTML и sitemap. Неизвестная тема отклонена до создания файла. Временная глава удалена.

## Ограничения

Проверка мобильной вёрстки выполнена в Chromium через iframe с реальным узким viewport, не на физическом телефоне. Локальный preview заблокирован отсутствующей службой sites-previewd; визуальные проверки проведены на опубликованном GitHub Pages. Остальные учебные материалы остаются планируемыми.
